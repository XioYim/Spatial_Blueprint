2. 物品数据（C12）：本批直读 / 直写物品 NBT 的地方一律走现有 public static 访问器 —— **访问器是静态方法、对任意 ItemStack 生效，与物品类型无关**：

   c. CaptureAreaMessage 往次元蓝图上写 captureMin / captureMax / creatorName、C2S_VoidRecaptureMessage 往新栈写同样三项 →
      VoidDimensionalBlueprintItem.setCaptureRange(stack, min, max) / setCreatorName(stack, name)（静态，组件与物品类型无关；BlockPos 内部已 immutable）。
   d. 映射见功能联动手册第二节；确实没有访问器的键写进报告，不要直接 set 组件绕过访问器。

3. 1.21 API（J43，云端已 javap）
   a. be.saveWithFullMetadata() → be.saveWithFullMetadata(player.registryAccess())（或 level.registryAccess()，报告写明用哪个）—— C23。
   b. BlockEvent.BreakEvent → net.neoforged.neoforge.event.level.BlockEvent.BreakEvent；MinecraftForge.EVENT_BUS.post → NeoForge.EVENT_BUS.post；isCanceled 不变 —— C23。
   c. Entity#save(CompoundTag) / saveWithoutId 在 1.21 签名不变，原样。
   d. ForgeRegistries.X.getKey → BuiltInRegistries.X.getKey（SBN-001 起的口径）。
   e. NbtUtils.writeBlockPos 在 1.21 写 int 数组 —— 本批凡是写进**物品**的坐标都已改走三.2.c 的访问器（组件），不再用它；
      写进**蓝图数据 / 文件**的坐标照 SBN-001 口径走 NbtCompat（1.20.1 若直接用 NbtUtils 写蓝图字段，改 NbtCompat 并进报告）。

4. 解码（K13 / K14）
   本批 5 个 decode 都只读定长字段与带上限的字符串，没有按客户端计数的分配（云端已查）。
   CaptureMode.fromOrdinal(buf.readInt()) 越界会抛 ArrayIndexOutOfBoundsException → NeoForge 断开该客户端，与 1.20.1 行为相同，**本任务不改**
   （功能联动手册已登记「fromOrdinal 不防越界」待查项，统一处理）。报告里列出本批所有 fromOrdinal 调用点。

5. 各要点（以 1.20.1 源码为准，只点风险处）
   a. CaptureAreaMessage：捕获冷却 checkAndUpdateCooldown → 找主 / 副手空白蓝图 → 两点 → 槽位 → validateCaptureArea → **FORCE 仅 OP（非 OP 降级 SAFE）** →
      次元蓝图只允许 SAFE → **clearAfterCapture 时逐块 BreakEvent 领地采样（非创造，或配置 DENY_CREATIVE_PLACEMENT_IN_PROTECTED_AREA 为 true 时创造也采）** →
      方块 / 方块实体 / 实体捕获（SAFE / SANITIZE / FORCE 各自的容器与实体规则）→ 写蓝图文件 → 次元蓝图清区域、材料入袋 → 换物品、发 S2C_CaptureCooldownMessage。顺序原样。
   b. CaptureProjectionMessage：不清源区域；非 FORCE 时容器内容 / 展示框物品 / 盔甲架装备 / 驮兽箱子不带走（防复制）；reward 只在 OP 且创造时生效。
   c. C2S_VoidRecaptureMessage：存档归属（belongsToCurrentWorld）→ 文件存在 → 主人校验（ownerUuidOf）→ 体积上限（OP 用绝对上限）→ 领地采样 → 覆盖写回原文件、清 placed。顺序原样。
   d. C2S_CreateEngineeringBlueprintMessage / C2S_CreateSubProjectMessage：照 1.20.1；CreateSubProject 里 stripItemContents(be.saveWithFullMetadata(provider)) 原样。
   e. SBUndoData / MaterialSpace / BlueprintLogger 的调用原样（均已迁）。
