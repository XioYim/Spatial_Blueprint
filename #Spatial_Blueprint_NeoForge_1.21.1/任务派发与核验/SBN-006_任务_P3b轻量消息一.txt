三、已定方案
========================================================

总原则同 SBN-005：字段、校验、上限常量、翻译键、日志文本、判断顺序一律不改；只按 BlueprintNetwork 类注释的改写口径（记忆 C14）改写。
每个文件 diff -w 残差逐条进报告。

1. BlueprintNetwork
   a. register 里追加 24 条：C2S 一律 playToServer、S2C 一律 playToClient（方向以 1.20.1 BlueprintNetwork.register 里 c2s / s2c 的归类为准）。
   b. 新增 public static void sendToAllPlayers(CustomPacketPayload payload) → PacketDistributor.sendToAllPlayers（J36）；
      替换 1.20.1 的 CHANNEL.send(PacketDistributor.ALL.noArg(), …)。类注释里的「发包一律走…」那句把它补进去。其余零改动。

2. 本批补充口径（C14 之外）
   a. 物品数据：消息里凡直接读写物品 NBT（stack.getTag() / getOrCreateTag()）的，一律改走物品类的 public static 访问器或
      SpatialBlueprintComponents（记忆 C12）；访问器已有就用访问器。
   b. 材料键：MaterialKey.of(stack) → MaterialKey.of(stack, player.registryAccess())（SBN-003 已改签名）；
      MaterialList.buildDisplayStack / getDisplayStack / MaterialSpace.displayStack 同理补 provider。
   c. 配置：ForgeConfigSpec.* → ModConfigSpec.*（SBN-001 已迁 ConfigRegistry，J37）；ConfigValue#save / set / get 名字不变（J37）。
   d. FriendlyByteBuf 的 writeBlockPos / readBlockPos / writeNbt / readNbt 在 1.21 仍在（J36），原样用。
   e. S2C：handle 体只要引用了客户端类（client / gui 包、net.minecraft.client.*、NotifySound 客户端方法）就整体打桩 SB-TODO(P5)；
      只写本类 static 字段、不碰客户端类的（先例 S2C_IllegalBlocksListMessage）原样保留。
      S2C 类里服务端用的构造 / 静态工厂（如 fromConfig、sendTo）原样保留，内部发包改走封装。

3. 各簇要点（以 1.20.1 源码为准，这里只点风险处）
   a. 物品状态 6 个：服务端改的是物品组件，改完的同步沿用 1.20.1 的写法（ItemSyncUtil 等）。距离 / 权限 / 手持判定原样。
   b. 配置：C2S_ApplyConfigMessage 的 MAX_ENTRIES、非 OP 拒绝、applyInt / applyBool / applyList 的计数与 save、
      「改了 BlueprintConfig → sendToAllPlayers(S2C_ConfigSyncMessage.fromConfig())」「改了替换表 → GeneratedSubstitutionsConfig save + invalidateCache」原样。
      S2C_ConfigValuesMessage 的客户端镜像（ClientConfigMirror）打桩；服务端组包用 ConfigRegistry.ints / bools / lists（已是 ModConfigSpec 类型）。
   c. 蓝图库：改名 / 转换 / 取回属性 / 删除 的 canManageBlueprint（或 1.20.1 的等价判定）原样；删除里的 BlueprintFileLogger 调用原样。
   d. 材料空间：C2S_MaterialDepositMessage 的扣背包 → 写 MaterialSpace → 回推 S2C_MaterialSpaceSyncMessage 顺序原样；
      S2C_MaterialSpaceSyncMessage 的 writeNbt / readNbt 与计数上限原样。
