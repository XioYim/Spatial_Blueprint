三、D8 实测：
1. 补丁 NBT 与 ItemStack.save 的 components 是同一个编码：ItemStack.CODEC 用 DataComponentPatch.CODEC.optionalFieldOf("components", EMPTY)（J20，源码），of() 用同一个 Codec + 同一序列化上下文；t02 对 7 个样本（石头 / 附魔剑 / 附魔+repair_cost / 改名剑 / 挖起来的空潜影盒 / 移除 FOOD 的苹果 / 装石头的潜影盒）逐一断言 of == make(id, save 出的 components 或 null)，全部相等。
2. "!" 移除标记真实形状：苹果 stack.remove(DataComponents.FOOD) 后 components = {"!minecraft:food": {}}（空 compound；证据 nbt_样本.txt removed-marker-components）——pruneNoOps 跳过该键，键与普通苹果不同（t01 断言 + t02 一致性）。
3. 附魔剑 components = {"minecraft:enchantments":{"levels":{"minecraft:sharpness":3,"minecraft:unbreaking":2}}}；加 repair_cost=7 后多 {"minecraft:repair_cost":7}，normalize 剔除（忽略项）后与未加的同键。
4. 空潜影盒：放下再挖起来（真实 ShulkerBoxBlockEntity.saveToItem）不产生任何组件（1.21 的 saveAllItems(…,false) 空列表不写、setBlockEntityData 空标签删组件），与合成空潜影盒同键（t01）；block_entity_data 剔 id 逻辑对旧格式数据仍有效（P4 用）。
5. 装石头的潜影盒：components."minecraft:container" = [{slot:0, item:{id,count}}]（槽位包一层，样本 shulker-with-components）。
