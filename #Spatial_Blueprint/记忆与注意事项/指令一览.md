# Spatial_Blueprint · 指令一览

> 全量指令清单（对标 Healthy_Diets `指令一览.md` 体例；本项目暂无对应 C 段，本文独立成文）。
> 依据源码整理（2026-09-23 首版，jar `spatial_blueprint-2.7.37.jar` / SHA256 `99476B69`…；服务端注册入口 `SBCommands.java:40`，经 `SpatialBlueprintMod.java:51` 挂到 Forge EVENT_BUS；客户端注册入口 `SBClientCommands.java:27`，共 2 根、19 叶、零遗漏）。
> 权限为原版 OP 等级（`hasPermission(n)`）：`[OP2]` = 2 级；`[全员]` = 无门槛（另有创造模式 / 手持物品等附加条件，见各条）。客户端 `/sbp` 系纯本地指令，无权限门。
> 游戏内无速查指令（无 `/sb help` / `/sbp help` 之类，所列每条只能看本文）。**改指令注册后请同步更新本文。**

## 服务端 `/sb`（`SBCommands.java:40`）

#### `/sb undo` — 撤回放置

| 条件 | 说明 |
| --- | --- |
| 仅玩家 | 控制台执行报 `undo.player_only` |
| 仅创造模式 | 生存模式报 `undo.creative_only` |
| 冷却中拒绝 | 报 `undo.cooldown`（剩余秒，向上取整） |
| 无历史拒绝 | 报 `undo.no_history`（`SBUndoData.pop` 取空） |
| 目标维度未加载拒绝 | 报 `undo.dim_unloaded` |

- 两种冷却（`SBUndoCooldown.java:16`，纯内存、重启清零）：放置时 `animDuration + 2 秒`；成功撤回后固定 `5 秒`。
- 成功后在目标维度执行 `BlueprintPlacementHandler.restoreUndo`，播 `BEACON_DEACTIVATE` 音，报 `undo.success`。
- 玩家登出清冷却（`SpatialBlueprintMod` 监听 logout 调 `clearPlayer`）。

#### `/sb config` — 打开配置页（OP2）

`requires(src -> src.hasPermission(2))` + 方法内 `player.hasPermissions(2)` 双保险；非玩家报 `undo.player_only`，无权限报 `config.error.no_permission`。成功给执行玩家发 `S2C_OpenConfigMessage`，客户端打开配置主页面。

#### `/sb reload` — 热加载配置（OP2）

调 `C2S_ReloadConfigMessage.doReload()`，成功报 `command.reload.success`（`[空间蓝图] 配置已热加载完成`），广播给 OP（`sendSuccess(..., true)`）。

#### `/sb space [玩家]` — 材料空间

| 用法 | 权限 | 说明 |
| --- | --- | --- |
| `/sb space` | 全员 | 查看自己的材料空间（普通池），`sendFullAndOpen(player, 自己的UUID, "")` 直接开界面 |
| `/sb space <玩家>` | OP2 | 查看指定玩家的材料空间；用 `GameProfileArgument`（不是 `EntityArgument.player()`），**离线玩家同样可查**；找不到报 `command.space.unknown_player` |

#### `/sb tpperm ...` — 传送权限（OP2，整支 `requires(hasPermission(2))`）

| 子命令 | 说明 |
| --- | --- |
| `grant <玩家>` | 授予；用 `GameProfileArgument`，离线可预授；目标在线立即 `syncTeleportPerm` 推送，界面按钮随之解锁；已有的报 `already_has` |
| `revoke <玩家>` | 移除；同上；本来没有的报 `not_has` |
| `list` | 列出被单独授予的玩家 UUID 集；空报 `list.empty`（顺带说明 OP 与创造玩家不受限）；非空先打 `list.header`（人数），逐行 ` - <名字> [移除]` |

- `list` 的 `[移除]` 是红色可点击文本，点击执行 `/sb tpperm revoke <名字>`（`RUN_COMMAND`），悬停 `revoke_tip`。
- 用**玩家名**拼命令（`revoke` 走 `GameProfileArgument` 认名字，传 UUID 解析不了）；名字查不到（从未上线，显示 UUID 本体）时**不给按钮**。
- 玩家登录时服务端主动推一次结论（`SpatialBlueprintMod.java:68` `onPlayerLogin` → `syncTeleportPerm`），否则客户端传送按钮一直显示无权限。

## 服务端 `/sb project`（项目蓝图）

#### `/sb project activate` — 激活项目（全员；公用项目需 OP + 创造）

主手必须持 `ProjectBlueprintItem`，且满足：未激活过（已有 `taskSetId` 报 `already_activated`）、已绑定项目（无 `projectId` 报 `unbound`）、项目文件存在、有尺寸、有子工程条目、子工程文件齐全、与他人 Claim 无重叠（报 `overlap`，带对方主人名与起点）。

- 公用项目（`item.isPublicProject()`）要求 `hasPermissions(2) && isCreative()`，否则报 `public_requires_op`。
- 成功：随机 `taskSetId` 写进手持物品（`setTaskSetId` + `syncHand`），写一条 Claim：起点 = 玩家站位，`max = origin + size - 1`；维度 = 玩家当前维度（`project.dat` 不记维度，激活时写）；`anchor = origin + (project.anchor - project.origin)` 且 `hasAnchor = true`（之后扩建只动 min/max，anchor 永不动）。
- 成功报 `activate.success`（任务集前 8 位 + 起点三坐标）。

#### `/sb project claim <序号>` — 领取子工程（全员）

| 用法 | 说明 |
| --- | --- |
| `/sb project claim <序号>` | `<序号>` 为 `integer(1)`（≥1）；转交 `SubProjectClaimHandler.claim(player, index)` |

- 已完成重建：报 `already_done`（success 通道，提示需先拆方块并再次耗材），同时仍可能跟一条 success。
- 失败分支（`sendFailure`，文案见 lang）：`need_item`（需手持项目蓝图）/ `not_activated` / `project_missing` / `claim_missing` / `no_such_entry`（无该序号）/ `prerequisite`（需先完成前置序号）/ `cooldown`（冷却秒）。
- 成功报 `claim.success`（子工程名 + 序号），`return 1`。

#### `/sb project release` — 释放项目（OP2）

取玩家站位，用当前维度 + 坐标 `findAt` 查 Claim；脚下无 Claim 报 `release.none`；有则 `removeByTaskSet` 删除，报 `release.success`（主人名 + 起点）。

#### `/sb project list` — 列出项目（OP2）

空报 `list.empty`；非空逐条 `list.entry`：`#<n> <主人> [<公用|私人>] 维度 <dim>，范围 (min) - (max)，任务集 <前8位>`，返回条数。

## 客户端 `/sbp`（`SBClientCommands.java:31`，全员本地、无权限门）

经 `RegisterClientCommandsEvent` 注册，只在客户端存在；单机 / 专服都能用，作用域**仅本客户端**。

#### `/sbp preview on|off` — 他人预览总开关

`ClientPreviewSettings.setEnabled(true/false)`，报 `client.preview.enabled` / `client.preview.disabled`。

#### `/sbp block|unblock <玩家>` — 按人屏蔽预览

| 用法 | 说明 |
| --- | --- |
| `/sbp block <玩家>` | `ClientPreviewSettings.block(name)`，报 `client.preview.blocked`；`<玩家>` 为 `word` 参数（单个词，不支持空格 ID） |
| `/sbp unblock <玩家>` | `ClientPreviewSettings.unblock(name)`，报 `client.preview.unblocked` |

#### `/sbp blocklist` — 屏蔽名单

空报 `client.blocklist.empty`；非空报 `client.blocklist`（逗号拼接）。

#### `/sbp download` — 下载他人预览数据

- 范围内无他人预览：报 `client.no_previews`，`return 0`。
- 恰 1 条：`OtherPlayerDownloadScreen.downloadEntry` 直下，报 `client.downloading`（对方名）。
- 多条：打开 `OtherPlayerDownloadScreen(entries)` 选择屏，`return 1`。

#### `/sbp clearcache` — 清客户端缓存

`ClientBlueprintCache.clearAll()`，报 `client.cache_cleared`。
