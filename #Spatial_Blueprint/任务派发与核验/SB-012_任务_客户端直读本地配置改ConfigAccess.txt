二、目标与背景
────────────────────────────────────────────────────────────────────────

问题（见开发日志 e55/e57）：
- 客户端约 36 处直接调 `BlueprintConfig.XXX.get()`，读的是本机 toml 里的旧值，绕过了
  `ConfigAccess` 的服务端镜像——服主在服务端改了 `PREVIEW_DISTANCE`、分档、时长上限后，
  客户端预览距离 / 取消余量 / OP 预估时长不跟（153/155）。
- `ConfigAccess.get(BlueprintConfig.XXX)` 读服务端镜像，没收到快照时回落本地——这才是正确入口。

`BlueprintConfig.getAutoDuration(int blockCount)` 是**双端共用**静态方法，内部调 `.get()`
（服务端侧正确，不能改方法本体）。客户端 `PointSelectionScreen.autoDurationSec()` 里调了它，
需要把 tier 判断**内联展开**、换成 `ConfigAccess.get()`——见 4.5。

不要做的：
- 不改 `BlueprintConfig.getAutoDuration()` 方法本体。
- 不新增网络消息、不改 `BlueprintNetwork.register()`、不 bump `mod_version`。
- 不改服务端文件（`network/CaptureAreaMessage.java` 等服务端消息里的 `.get()` 是对的）。
- 不改 `ConfigAccess.java` 本身（已有全部所需的 `get(IntValue)` / `get(BooleanValue)` 重载）。
- 不构建、不部署（主会话统一处理）。

4.5 gui/PointSelectionScreen.java —— autoDurationSec() + getTimeSec()
━━━━━━━━━━━━━━━━━━

**autoDurationSec()（约 :379–382）**：当前实现调 `BlueprintConfig.getAutoDuration(cachedBlockCount)`。
`getAutoDuration` 是双端共用静态方法，不能改它本体。
**把判断内联展开**，全部换成 `ConfigAccess.get()`：

  public int autoDurationSec() {
      int n = Math.max(0, cachedBlockCount);
      if (n < ConfigAccess.get(BlueprintConfig.BUILD_TIME_TIER1_MAX_BLOCKS)) return ConfigAccess.get(BlueprintConfig.BUILD_TIME_TIER1_SECONDS);
      if (n < ConfigAccess.get(BlueprintConfig.BUILD_TIME_TIER2_MAX_BLOCKS)) return ConfigAccess.get(BlueprintConfig.BUILD_TIME_TIER2_SECONDS);
      if (n < ConfigAccess.get(BlueprintConfig.BUILD_TIME_TIER3_MAX_BLOCKS)) return ConfigAccess.get(BlueprintConfig.BUILD_TIME_TIER3_SECONDS);
      if (n < ConfigAccess.get(BlueprintConfig.BUILD_TIME_TIER4_MAX_BLOCKS)) return ConfigAccess.get(BlueprintConfig.BUILD_TIME_TIER4_SECONDS);
      if (n < ConfigAccess.get(BlueprintConfig.BUILD_TIME_TIER5_MAX_BLOCKS)) return ConfigAccess.get(BlueprintConfig.BUILD_TIME_TIER5_SECONDS);
      if (n < ConfigAccess.get(BlueprintConfig.BUILD_TIME_TIER6_MAX_BLOCKS)) return ConfigAccess.get(BlueprintConfig.BUILD_TIME_TIER6_SECONDS);
      return ConfigAccess.get(BlueprintConfig.BUILD_TIME_TIER7_SECONDS);
  }

改完用 `grep -n "getAutoDuration\|BUILD_TIME_TIER.*\.get()" PointSelectionScreen.java` 确认 0 处残留。

**getTimeSec()（约 :388–395）**：改两行：
  原：`int minSec = BlueprintConfig.ANIMATION_DURATION_MIN.get();`
      `int maxSec = BlueprintConfig.ANIMATION_DURATION_MAX.get();`
  改：`int minSec = ConfigAccess.get(BlueprintConfig.ANIMATION_DURATION_MIN);`
      `int maxSec = ConfigAccess.get(BlueprintConfig.ANIMATION_DURATION_MAX);`

`PointSelectionScreen` 是 `gui` 包客户端专属界面，import ConfigAccess 无安全风险。
