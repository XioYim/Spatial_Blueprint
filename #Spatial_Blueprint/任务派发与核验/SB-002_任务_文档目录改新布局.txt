七、子序列校验怎么做（第八步 A、B 项用）
------------------------------------------------------------------
两边都先「归一化」：去掉全部空白字符，再去掉这些标记字符 # * | - _ > ` [ ] ( ) < > ~ ✓ ✗ ☐ 以及 HTML 实体解码后的同类字符；
然后判断「源文本」是不是「目标文本」的字符子序列（逐字符按顺序能全部找到）。PowerShell：

    function Norm([string]$s){ $s = [System.Net.WebUtility]::HtmlDecode($s); return ([regex]::Replace($s, '[\s#*|\-_>`\[\]()<~✓✗☐]', '')) }
    function IsSubseq([string]$src,[string]$dst){ $i=0; foreach($c in $dst.ToCharArray()){ if($i -lt $src.Length -and $src[$i] -eq $c){ $i++ } }; return ($i -eq $src.Length) }
    # 源：旧 .md 原文；目标：html2text.ps1 -Path <新html> 的输出，或新 .md 原文
    $src = Norm ([IO.File]::ReadAllText('<旧文件>', [Text.Encoding]::UTF8))
    $dst = Norm ((& 'D:\Mods\项目工具\html2text.ps1' -Path '<新文件>' | Out-String))
    IsSubseq $src $dst      # 必须 True；False 时二分缩小范围找到第一处对不上的字符，写进报告

不迁的内容（备份表的 13 行、标记图例、示例条目、「在做什么」里已在日志的经过）在做子序列校验前先从源文本里剔除，剔除了什么写进报告「改动」段。
