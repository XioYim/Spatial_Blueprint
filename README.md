# Spatial Blueprint

**Minecraft 1.21.1 · NeoForge 21.1.252**（本分支 `neoforge-1.21.1`，移植中；Forge 1.20.1 版在 `main` 分支）  
作者：xioyim · 版本：3.0.0

---

## 简介

Spatial Blueprint 是一个结构捕捉与放置 mod。  
选定区域后将其保存为蓝图，随时在世界任意位置预览并还原整个结构，支持旋转、偏移调整和逐块动画放置效果。

蓝图分为四种类型，适用于不同场景：

| 类型 | 创建方式 | 放置方式 | 次数 |
|---|---|---|---|
| 空间蓝图 | 创造模式 | 任意模式 | 无限；创造保留物品，生存放置后立即删除物品 |
| 投影蓝图 | 任意模式 | 任意模式 | 无限；含材料清单，生存模式需存入材料 |
| 次元蓝图 | 任意模式 | 任意模式 | 创造无限，生存一次性（冷却后返回空置次元空间） |
| 工程蓝图 | 创造模式 | 生存模式 | 含材料清单，建造后返回空白工程蓝图 |

## 物品

### 空白蓝图（Blank Blueprint）
用于选取捕捉区域，根据设定生成对应类型的蓝图。

**使用方法：**
1. 手持空白蓝图右键任意方块或在空中右键，打开**蓝图设定界面**。
2. 在界面中为蓝图命名（默认名称"**新蓝图**"），选择蓝图类型（空间 / 投影 / 次元）。
3. 点击**起点**按钮后右键设置区域起始角（绿色高亮）。
4. 点击**终点**按钮后右键设置区域对角位置（红色高亮）。
   - 也可点击起点/终点之间的 **✎** 按钮，直接输入 X/Y/Z 坐标数值（支持负数；保存时自动检查捕获上限，超限在聊天框提示）。
5. 两点确定后界面显示选区尺寸与非空气方块总数，可用方向键微调坐标。
6. 点击**创建**，捕捉选区内所有方块，生成对应类型的蓝图。

> 选区内含有 Bedrock、刷怪笼、命令方块等受保护方块时，捕捉操作会被拒绝。  
> 选区内**非空气方块数**（含流体）受服务端配置限制，默认：创造 300,000 / 生存 100,000，超出时在**聊天框**提示"超出捕获数量限额"。配置项在 `spatial_blueprint.toml` 的 `maxCaptureVolumeCreative` / `maxCaptureVolumeSurvival`。  
> ✎ 坐标编辑界面保存时会根据服务端同步到客户端的上限提前校验，避免等到点击创建才被拒绝。  
> 所有操作反馈（成功 / 失败 / 错误）均通过**聊天框**输出，不使用 hotbar 上方悬浮文字。

### 空间蓝图（Spatial Blueprint）
仅创造模式可捕捉，生存模式文件无需材料可免费构建，一次性蓝图。

**使用方法：**
1. 手持空间蓝图右键，打开**蓝图放置界面**。
2. 切换**对齐模式**（关 → 起点 → 中心 → 终点 → 关）来控制预览锚点：
   - **关**：不显示幽灵预览，放置按钮禁用。
   - **起点**：建筑最小角对准准星方块。
   - **终点**：建筑最大角对准准星方块。
   - **中心**：建筑水平中心对准准星方块。
3. 使用方向按钮（↑↓←→▲▼）在锚点基础上微调偏移量。
4. 使用 🔁 旋转结构（每次顺时针 90°）。
5. 点击 🔒 **锁定**，将预览固定在当前目标位置，方便精确微调；再次点击 🔑 解锁。
6. 切换 **▰ / ▱ 清空模式**：
   - **▰ 清空区域**：放置前先清空整个包围盒内所有方块，再逐帧动画还原。
   - **▱ 替换方块**：跳过清空，仅覆盖蓝图方块所在位置；包围盒内其他方块保持不变。  
     ⚠ 替换模式下，范围外依附方块（火把、红石等）可能因支撑消失而掉落。
7. 确认位置后点击**放置**，结构以动画形式逐块还原。
8. 点击 **⟲ 关闭**，保留当前偏移 / 旋转状态并关闭界面；点击 **✖ 取消**，清除所有操作状态并关闭界面（无冷却惩罚）。
9. 点击 **⛖/⛗/♨**（Row 2）4 档循环切换流体显示模式；点击 **⛒/❶/❷/❸** 切换方块遮蔽模式。

| 模式 | 放置后行为 |
|---|---|
| 创造模式 | 物品保留，可无限放置 |
| 生存模式 | 物品立即删除，无冷却，无返还 |

**创建工程蓝图（⌘ 按钮）：**  
放置界面中，当预览激活（对齐模式非关）时，创造模式玩家可点击 **⌘** 按钮打开**创建工程项目界面**，将当前预览的坐标范围和维度固化为一个工程蓝图文件，供生存玩家使用。

### 投影蓝图（Projection Blueprint）
任意模式均可捕捉，含**材料清单**，放置方式与空间蓝图相同，可无限次放置。

**使用方法：** 与空间蓝图相同（含 🔒 锁定 和 ▰/▱ 清空模式切换），另有以下区别：

- 放置界面下方有**材料清单**面板（点击"材料清单"按钮展开 / 收起）。
- 材料清单以 4 列小图标展示每种方块，每格显示 **已存入 / 需要** 数量；绿色 = 充足，金色 = 不足。
- 鼠标悬停图标显示方块名称；创造模式下可右键图标弹出操作菜单。
- 生存 / 冒险模式下，**构建按钮**在材料未充足时显示"材料不足"并禁用，充足后恢复正常。
- 放置后转变为**构建中蓝图**，倒计时结束后恢复为投影蓝图。

**材料存取（所有模式）：**

| 操作 | 位置 | 功能 |
|---|---|---|
| 点击 ✎ 按钮 | 面板标题栏 | 快捷存入：自动将背包中所有所需材料存入蓝图（生存消耗背包物品，创造直接填满） |
| 点击 ♻ 按钮 | 面板标题栏 | 快捷取出：将蓝图中已存入的全部材料一键退回背包（背包满格后掉落在地） |
| 右键图标（创造） | 材料格 | 弹出菜单：复制名称 / 复制 ID / 修改数量 / **存入** / **取出** / 删除 |
| 点击 ✚ 按钮（创造） | 面板标题栏 | 打开背包物品选择器，点击物品新增到清单 |

> **存入的物品随蓝图物品存储**（ItemStack NBT `depositedMaterials`）。蓝图物品丢失时，其中存入的材料一并丢失，请谨慎操作。  
> 生存模式放置时服务端会消耗全部已存入材料；放置后蓝图自动清空存入记录。  
> 创造模式无需存入材料即可放置，存取操作不消耗 / 返还任何物品。

### 次元蓝图（Dimensional Blueprint）
任意模式均可捕捉（点击捕捉界面中的**储存**按钮创建），捕捉时同步清除选区内所有方块。行为与空间蓝图相同，但具备单次性。

**使用方法：** 与空间蓝图相同。

| 模式 | 放置后行为 |
|---|---|
| 创造模式 | dat 文件**不删除**，物品保留，可无限放置 |
| 生存模式 | dat 文件**删除**，进入冷却，冷却结束后返回**空置次元空间** |

> 强制取消时 dat 文件不删除，冷却结束后返回次元蓝图本身。

### 空置次元空间（Void Dimensional Space）
生存模式下次元蓝图放置完成后进入冷却、冷却结束时获得的特殊物品。  
记录了当初捕捉的坐标范围，可原地重新捕捉结构以生成新的次元蓝图。  
悬停 tooltip 显示捕捉范围的**起点**和**终点**坐标；尚未绑定时显示占位提示。

**右键**打开**空置次元空间界面**，提供五个操作：

| 按钮 | 功能 |
|---|---|
| Tp | 仅 OP 可用：传送到次元蓝图**放置时玩家所在位置**（维度需一致）；若未记录坐标则传送到 captureMin/captureMax 较近者 |
| 查看范围 | 在原捕捉坐标处显示蓝色轮廓框，确认范围位置；走远超过 `renderCancelMargin`（64 格）后自动关闭 |
| 储存 | 在原坐标重新捕捉该区域内的所有方块，生成新的次元蓝图（同步清除原区域方块） |
| 重置 | 放弃坐标记录，将物品还原为空白蓝图（需二次确认，不可撤销） |
| 取消 | 关闭界面，不做任何操作 |

> 传送坐标在次元蓝图放置时自动记录（玩家位置 + 维度），经由 `BuildBlueprintItem` 传递到空置次元蓝图 NBT（`tpX/Y/Z` + `tpDimension`）。

### 工程蓝图（Engineering Blueprint）
由**创造模式玩家**从蓝图放置界面的 ⌘ 按钮创建，固定建造位置，供**生存玩家**使用。  
材料存取机制与投影蓝图相同；构建消耗材料，完成后返回空白工程蓝图。

**创建流程（创造模式）：**
1. 手持投影蓝图（或空间蓝图），在放置界面中开启预览（对齐模式非关）并调整好位置。
2. 点击 **⌘** 按钮，打开**创建工程项目界面**：
   - 输入工程名称（预填入蓝图名）。
   - 设置最大操作距离（默认 64 格；生存玩家距施工坐标超出此值时无法触发）。
   - 界面只读显示当前维度及固化的起点 / 终点坐标。
3. 点击**创建工程**，服务端保存工程蓝图文件（`engineering/` 目录），并将手中的蓝图替换为已绑定工程坐标的**工程蓝图**。

**使用流程（生存模式）：**
1. 手持工程蓝图右键，打开**工程蓝图界面**（含材料清单面板）。
2. 先存入所有所需材料（同投影蓝图的存入操作）。
3. 点击**开启预览**，在固化的坐标处显示橙色轮廓幽灵预览（需在维度内且距离内）；
   再次点击**关闭预览**可收起。
4. 预览开启后，**构建工程**按钮激活；点击后消耗材料、触发动画放置，物品变为**构建中蓝图**。
5. 倒计时结束后返回**空白工程蓝图**（坐标绑定清除，可重新绑定）。

**界面按钮：**

| 按钮 | 功能 |
|---|---|
| Tp | 仅 OP 可用：传送到此蓝图的安全坐标（若已设定），否则传送到起点/终点中较近的一个；需与蓝图维度一致 |
| 材料清单 | 展开 / 收起材料面板 |
| 开启预览 / 关闭预览 | 切换固化坐标处的橙色幽灵预览（不满足维度或距离限制时禁用并显示原因） |
| 构建工程 | 触发建造（需预览开启且材料充足） |
| 关闭 | 关闭界面，保留状态 |
| 取消 | 关闭预览并关闭界面 |
| ⌘ | 仅创造模式可用：打开工程菜单（蓝图库的工程标签页） |

**Tooltip 信息：**  
悬停工程蓝图显示材料种类 / 总数；绑定工程后额外显示施工起点和终点坐标。

### 构建中蓝图（Building Blueprint）
放置操作进行期间的过渡物品，持有者无法再次放置，需等待倒计时归零。

- 鼠标悬停显示剩余秒数（黄色）或"就绪"（绿色）。
- 倒计时 = 动画时长 + `extraCooldownSeconds`（配置项，默认 10 秒）。
- 归零后服务端自动恢复为对应蓝图类型（投影 / 次元 / 工程等）。

### 蓝图库（Blueprint Library）
点击放置界面右侧的 **✚** 按钮（仅创造模式）打开蓝图库，浏览、加载或管理已保存的蓝图文件。  
蓝图库包含 **create**（空间）、**project**（投影）、**dimensional**（次元）三个标签页。

**搜索框**：标签栏下方有长条搜索框，实时按名称过滤列表；切换标签页时自动清空搜索词。  
**滚动条拖拽**：支持点击或拖拽右侧滚动条快速跳转；同时支持鼠标滚轮滚动列表区域。

> 工程蓝图不在常规标签页中显示；通过工程蓝图界面右侧的 **⌘** 按钮打开**工程菜单**，仅展示 `engineering/` 目录下的工程蓝图文件。

**多人模式支持：** 在多人游戏中，列表通过网络从服务端拉取（打开时自动发送请求，期间显示"正在从服务器加载…"）；✎ 重命名和 ✖ 删除操作同样经 C2S 包路由至服务端执行，其余操作（✂ 修改时长、✦ 取出经验、☀ 取出次数、✔ 应用）已内置 C2S 支持，无需额外适配。

每行蓝图显示蓝图名称及居中的统计信息（**材料清单 / 构建耗时 s**），提供操作按钮：

| 按钮 | 标签页 | 模式 | 功能 |
|---|---|---|---|
| ✎ | 全部 | 全部 | 重命名蓝图 |
| ⎙ | 全部 | 全部 | 复制文件名（UUID.dat）到剪贴板 |
| ✂ | 全部 | 全部 | 修改放置时间（最低 `animationDurationMin` 秒，默认 3 s） |
| ✔ / ✚ | 全部 | 全部 | 应用此蓝图（替换手中物品）；工程菜单模式下改为加载 |
| ✖ | 全部 | 全部 | 删除此蓝图（需二次确认 |
| ✦ | project / engineering | 创造 | 设定取出经验等级消耗（-1 清除，恢复默认公式） |
| ☀ | project / engineering | 创造 | 设定取出最多次数（-1 清除，恢复配置默认值） |

**名称悬停 Tooltip** 显示蓝图名称（白色）、材料清单数量（绿色）、构建耗时（青色）、创建玩家（黄色）、创建日期（灰色），以及 project / engineering 蓝图的起点 / 终点坐标和最大距离。工程菜单模式下额外显示灰色斜体"点击设定传送坐标/快捷传送"提示（若已设定安全坐标则附加坐标值）；点击名称可打开**安全坐标设定界面**。

**安全坐标设定界面（SafeCoordScreen）：**  
OP 专属，从工程菜单点击项目名称打开。可为每个工程蓝图配置一个安全传送坐标（X/Y/Z），点击"设定为当前坐标"自动填入玩家当前位置；勾选"允许生存玩家传送"可开放非 OP 玩家使用 Tp 按钮。安全坐标通过 `SBSafeCoordData`（world `SavedData`，key `sb_safe_coord`）持久化存储于服务端，多人模式下经 `C2S_SafeCoordMessage` 同步。

## 视觉效果

- **选区轮廓**：起点绿框、终点红框、完整选区蓝色轮廓，附带动态扫描线效果。
- **放置预览（空间 / 投影 / 次元蓝图）**：使用 GPU VBO（VertexBuffer）缓存渲染方块幽灵，全亮度光照（`BlueprintFakeWorld`），无透明度。大型蓝图（10 万 + 方块）以异步线程在后台完成 CPU 端网格构建，渲染线程按 4096 个/帧分批上传 GPU，避免单帧卡顿；方块逐帧出现直至全部上传完成。画和展示框属于实体，不参与幽灵渲染，仅在实际放置后出现。
  - **流体**（水 / 岩浆 / 模组流体）：以**纯色不透明色块**渲染（不使用动态贴图），水色和岩浆色可在配置文件 `fluidPreviewColorWater` / `fluidPreviewColorLava` 中指定 6 位十六进制颜色值（默认水蓝 `3F76E4`、岩浆橙 `FF6400`）。流体色块与普通方块一同构建进 VBO，不再每帧采样动态贴图，大幅降低含大量流体蓝图的渲染开销。
    - **放置界面流体模式（4 档循环）**：⛖白 显示全部不过滤 → ⛗白 隐藏水+岩浆不过滤 → ⛖红 隐藏水+岩浆且放置时跳过 → ♨红 隐藏全部流体（含模组）且放置时跳过。影响放置（红色按钮）时蓝图数据在服务端过滤，流体方块不会被放置。
    - **捕捉界面流体过滤（♨，4 档循环）**：♨白 录入全部流体 → ♨蓝 不录入水 → ♨橙 不录入岩浆 → ♨红 不录入任何流体。过滤在服务端捕捉时执行，被过滤流体不写入蓝图数据。
    - 隐藏范围由配置 `hiddenPreviewBlocks` 控制，默认含水、岩浆、气泡柱；♨ 档位下所有流体状态方块均被隐藏，无需另行配置。
  - **晚放置方块**（箱子、潜影盒等）：预览时在对应位置显示**浮动文字标签**，标注该位置应放置的方块名称。
  - **方块遮蔽模式（⛒/❶/❷/❸）**：隐藏材料清单中用量最多的 1/2/3 种方块预览，便于查看被主要用料遮挡的内部结构；关闭（⛒）时恢复全部显示。
- **工程蓝图固定预览**：在绑定的固化坐标处以**橙色轮廓 + 半透明幽灵**显示，不随准星移动；在工程蓝图界面中通过"开启预览"按钮触发，超出距离或维度限制时自动关闭。
- **动画放置**：方块以随机顺序逐批出现，每个位置先短暂显示 `RenderBlock` 占位（硬度 0.3，与玻璃相同）再变为真实方块，伴随信标音效。

## 文件存储

蓝图数据保存在 `config/spatial_blueprint/` 下：

```
config/spatial_blueprint/
├── spatial_blueprint.toml  ← mod 配置文件
├── create/                 ← 空间蓝图（.dat）
├── project/                ← 投影蓝图（.dat）
├── dimensional/            ← 次元蓝图（.dat）
└── engineering/            ← 工程蓝图（.dat）
```

旧版本存放在根目录的 `.dat` 文件向后兼容，仍可正常读取。  
**删除蓝图时，对应的 `_mat.dat` 材料清单文件同步删除，不留磁盘孤儿。**

## 配置（`config/spatial_blueprint/spatial_blueprint.toml`）

### `[general]`

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `excludedBlocks` | 基岩、刷怪笼、命令方块等 | 不可被捕捉的方块列表 |

## 技术细节

- **客户端 / 服务端分离**：所有放置逻辑均在服务端执行，客户端仅负责 GUI 和渲染预览。多人模式下 `ProjectionBlueprintItem` / `EngineeringBlueprintItem` 的蓝图数据通过 `ClientBlueprintCache` 在客户端内存缓存（最多 256 条，超限后驱逐最旧条目），`AbstractBlueprintItem.getBlueprintData()` 在客户端侧优先查缓存，避免无谓的文件 I/O 和联机时的空数据问题。

- **多人蓝图库**：蓝图库界面在多人游戏中通过 `C2S_RequestLibraryMessage` 向服务端请求摘要列表，服务端以 `S2C_LibrarySyncMessage` 回复并由 `ClientLibraryCache`（库列表专用缓存）持有；✎ 重命名通过 `C2S_RenameBlueprintMessage`、✖ 删除通过 `C2S_DeleteBlueprintMessage` 路由至服务端执行，成功后服务端推回最新列表。单人模式直接读取本地文件，路径不变。

- **网络包校验**：服务端对捕捉区域、放置坐标、偏移量均做范围和合法性校验，拒绝超出限制的请求；工程蓝图的固化坐标、包围盒边长（≤ 1024 格）和最大距离（[1, 99999]）均在服务端二次验证。材料清单编辑包服务端二次验证创造模式身份。`C2S_ApplyBlueprintMessage`（蓝图库应用）服务端验证创造模式，防止生存玩家伪造数据包替换手中物品。`C2S_RequestBlueprintDataMessage`（蓝图数据下载）服务端限速：同一玩家 500 ms 内重复请求静默丢弃，防止恶意刷包。

- **捕捉体积计量**：`maxCaptureVolume` 配置项统计的是选区内**非空气方块数量**（含流体），不含空气格。`BlueprintValidator.validateCaptureArea()` 采用两阶段检查：先用包围盒体积做 O(1) 预检（超过绝对上限 20 万直接拒绝），通过后再逐格扫描统计非空气数与配置上限比较。`C2S_VoidRecaptureMessage`（次元蓝图重捕捉）复用同一 `countNonAir()` 方法保持一致。

- **材料存取系统**：存入量以 `depositedMaterials`（CompoundTag：blockId → int）存储在蓝图 ItemStack NBT 中。`PlaceBlueprintMessage` 生存模式分支在调用放置逻辑前调用 `hasSufficientMaterials()` 二次校验，通过后调用 `clearDepositedMaterials()` 消耗材料。快捷取出采用**两阶段提交**：Phase 1 全量将物品归还到玩家背包，Phase 2 再全量清零已存量、扣除经验、递增取出计数——服务端崩溃于 Phase 1 中途时，材料记录仍完整，玩家可安全重试。客户端 `localDeposited` 乐观跟踪存入状态，每次存取后立即刷新 UI，确保"材料不足"按钮状态实时准确。

- **工程蓝图约束**：`PlaceBlueprintMessage` 工程分支调用 `EngineeringBlueprintItem.checkProjectBounds()` 验证玩家所在维度与距离；客户端 `BlueprintSelectionRenderer.onClientTick()` 同样每 tick 检查约束，违反时静默关闭预览并退出界面。

- **四轮放置系统**：方块分为"普通"（带动画）、"依赖"（需等支撑）和"延迟"（容器类）三类。`forcePlaceAllBlocks` 分四轮：①清理残余 `RenderBlock`，②瞬间放置依赖方块（门、床、植物、铁轨、红石、告示牌、藤蔓等），③召唤装饰实体（画、展示框），④强制放置延迟方块（箱子、熔炉等，确保 NBT 正确写入）。向下生长的方块（垂泪藤、洞穴藤蔓）在依赖轮内按 Y 降序排列。

- **RenderBlock 自替换**：`RenderBlockEntity.tickServer()` 内部计数，动画时长结束后自动将自身替换为目标方块，无需等待强制清理轮。

- **画与展示框**：捕捉时保存完整 NBT（移除 UUID），存入 `BlueprintData.entities`；放置时对附着坐标和朝向同步应用旋转变换。

- **物品同步**：蓝图的偏移、旋转等 NBT 通过专用网络包在客 / 服之间同步；偏移和旋转在点击放置时内嵌进 `PlaceBlueprintMessage.finalOrigin`，服务端无需提前存储。服务端每秒（20 tick）扫描一次玩家背包，检测冷却到期并还原物品类型。

- **自动取消**：投影蓝图距离超出阈值时仅重置对齐模式，不发送 `ForceCancelMessage`（投影蓝图不被消耗）；次元蓝图超出阈值后进入冷却（dat 文件不删除，冷却结束返回次元蓝图）。空置次元空间的"查看范围"预览框同样在超出 `renderCancelMargin` 后静默清除。右键重新打开菜单时，若检测到 AlignMode 非 OFF、未锁定且准星超出预览距离，`SpatialBlueprintItem.openPlacementScreen()` 自动执行取消逻辑（重置全部状态），再打开初始状态菜单。

- **VBO 幽灵渲染**：`BlueprintSelectionRenderer` 使用 `VertexBuffer` 缓存方块几何，结合 `BlueprintFakeWorld`（实现 `BlockAndTintGetter`）提供全亮度光照与邻居数据。幽灵以 `rendertype_translucent` 着色器渲染，`drawWithShader` 前将 `ChunkOffset` uniform 置零，防止残留地形偏移导致幽灵位置错位。CPU 端网格构建在低优先级后台线程完成；GPU 上传在渲染线程按 4096 块/帧分批执行。`ClientBlueprintCache` 在单人模式首次文件加载后即填入，避免后续每帧重复文件 I/O（原 63ms/帧卡顿）。流体方块（水 / 岩浆）不再使用动态贴图渲染，而是在 `buildChunks()` 中以**纯色 6 面体**构建进同一 VBO：UV 指向静态白色混凝土贴图（`white_concrete`），顶点颜色由配置 `fluidPreviewColorWater/Lava` 决定，乘以白色贴图后直接输出配置颜色；延迟方块（箱子等）继续以每帧浮动文字标签显示，不进 VBO。这一改变消除了流体预览的逐帧 TextureAtlasSprite 动画贴图采样和 BiomeColors 生物群系水色计算，从根本上解决含大量流体蓝图时开启预览帧率明显下降的问题。

- **预览包围盒缓存**：`BlueprintSelectionRenderer` 以 `blueprintId`（字符串）而非数据对象引用作为包围盒缓存键，确保单人模式下每帧 `BlueprintStorage.load()` 返回新对象时缓存仍然命中，不会退化为每帧全量遍历。

- **方块替换**：`MaterialList.fromBlueprintData()` 在统计材料时查询配置中的 `blockSubstitutions` 表并合并计数；替换仅影响材料清单，不影响 `BlueprintData.normalBlocks` 中存储的原始方块状态。

- **次元蓝图单次性**：`PlaceBlueprintMessage` 处理时检测 `isDimensional`，放置开始后立即调用 `BlueprintStorage.delete()` 删除 dat 文件；创造模式跳过此步骤。

- **`/sb undo` 撤回系统**：创造模式空间蓝图放置前自动对整个包围盒（方块 + BlockEntity NBT + 画/展示框实体 NBT）做快照，存入 `SBUndoData`（world `SavedData`，key `sb_undo_history`）。放置后冷却 = 动画时长 + 2 秒，保证动画完成后方可执行撤回。`/sb undo` 执行后立即瞬间还原整个区域（两阶段清空 → 两阶段还原 → 实体重召唤），不分批，相当于结构方块效果；成功后进入 5 秒防连按冷却。每玩家历史条数默认 6 条，可通过 `maxUndoHistory`（范围 2–16）配置。

- **延迟放置分类**：捕捉时对每个方块先检查 `latePlaceBlocks` 配置，命中则归入 `lateBlocks`；否则再检查 `isDependent()`；最后归入 `normalBlocks`。分类优先级：延迟 > 依赖 > 普通。

- **蓝图文件安全**：`BlueprintStorage` 加载时限制文件大小上限为 64 MB，拒绝超大文件防止 OOM；`BlueprintValidator.checkAndUpdateCooldown()` 使用 `ConcurrentHashMap.compute()` 原子操作消除并发竞态；`BlueprintData.DEPENDENT_CACHE` 设上限 4096 条防止边界条件下的无界增长。
